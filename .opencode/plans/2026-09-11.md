# Plan: Chat Wallpaper Picker Feature (Corrected)

## Context
User wants a chat wallpaper feature for ocode — background images behind the chat panel, with support for light and dark themes, developer-oriented and cute/girly themes, configurable via settings, with thumbnail browsing and custom upload support.

## Goals
1. Display a wallpaper image as the chat panel background (CSS `background-image` on the chat container)
2. Provide built-in wallpapers categorized by theme (light, dark, developer, cute/girly)
3. Settings UI with thumbnail grid + category tabs to browse/select wallpapers
4. User upload support: upload custom photos stored in the ocode global data dir
5. Wallpaper state persisted in ocodeconfig.json with stable wallpaper IDs
6. Light/dark aware: different wallpapers auto-selected based on current color scheme via CSS media query

## Corrected Approach (per advisor review)

### Schema (FIXED)
Stable wallpaper IDs, explicit light/dark selections, mode, and enabled flag:
```go
type WallpaperConfig struct {
    Enabled bool   `json:"enabled"`
    LightID string `json:"light_id"`  // wallpaper ID for light mode
    DarkID  string `json:"dark_id"`   // wallpaper ID for dark mode
    Mode    string `json:"mode"`      // "auto" | "light" | "dark"
}
```
No filesystem paths — only registered wallpaper IDs.

### Storage (FIXED)
- Global data dir via `paths.OcodeGlobalDataDir()` → `<dir>/wallpapers/`
- Built-in SVGs generated procedurally on first run into this dir
- Uploaded files stored in `<dir>/wallpapers/user/` with safe random filenames
- Server serves only registered IDs (whitelist), enforces size/MIME/dimension/filename/path-traversal limits

### Assets (FIXED)
- Procedural SVG generation only (no third-party downloads)
- Wallpapers generated as SVG patterns/gradients at runtime on first access
- Categories: dark, light, developer, cute — each with distinct visual style

### Shared State (FIXED)
- New `useWallpaperConfig()` hook: reads wallpaper config once on mount, exposes `config` + `mutate` function
- Both SettingsPanel (wallpaper picker) and ChatPanel (background) use this hook
- Avoids per-ChatPanel fetch duplication
