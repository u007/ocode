# Plan: Set localhost:3201 as default sync URL

## Change
In `internal/sync/sync.go`, change `DefaultBaseURL()` fallback from `"https://kakiit.com"` to `"http://localhost:3201"`.

## Rationale
The Kakiit server runs locally on port 3201. The public `kakiit.com` is unreachable (DNS resolves to an IP that times out). The env var `OCODE_SYNC_URL` already provides an override for non-local setups.

## Implementation Steps
1. Edit `internal/sync/sync.go` line 24: change `return "https://kakiit.com"` to `return "http://localhost:3201"`
2. Verify with `go build ./internal/sync/`
3. Verify with `curl -s localhost:3201/api/ocode/device/start -X POST -d '{}'`
