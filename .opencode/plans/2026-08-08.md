# Plan: Convert main tabs to Radix Tabs

**Created:** 2026-08-08 00:48:06 +08
**Status:** Ready

## Context

Main content tabs (chat, agents, files, etc.) use conditional rendering (`{activeTab === "x" && <Panel />}`) which unmounts panels on switch, causing re-renders and lost state (scroll positions, cursors). No `React.memo` exists anywhere.

## Goals

- All tab panels stay mounted when switching (CSS visibility toggle)
- Use existing shadcn Radix Tabs component (`ui/tabs.tsx`) for accessibility + keyboard nav
- Preserve all current visual styling and behavior

## Files to Change

1. `web/src/components/ui/tabs.tsx` — add `forceMount` support to `TabsContent`
2. `web/src/components/Layout/TopTabs.tsx` — replace custom buttons with Radix `<TabsTrigger>`
3. `web/src/App.tsx` — wrap content in `<Tabs>`, use `<TabsContent forceMount>` with visibility toggle

## Implementation Steps

1. **`ui/tabs.tsx`**: Update `TabsContent` to pass through `forceMount` prop from Radix. Apply `data-[state=inactive]:hidden` class so inactive content is hidden but mounted.

2. **`TopTabs.tsx`**: Wrap everything in `<Tabs value={activeTab} onValueChange={onTabChange}>`. Replace main tab `<button>`s with `<TabsTrigger value={tab.id}>`. Keep editor tabs as `<TabsTrigger>` too. Preserve existing icon/label/close styling by overriding Radix's default `data-[state=active]` styles.

3. **`App.tsx`**: Replace conditional rendering (`{activeTab === "x" && ...}`) with `<TabsContent value="x" forceMount>` for each panel. Editor tabs get the same treatment. Remove the wrapper `<div className="flex-1 overflow-hidden">` and put `<Tabs>` there instead.

## Risks & Considerations

- Editor tabs are dynamic (`editor-<path>`) — Radix handles values not in any trigger fine
- `forceMount` keeps DOM alive — memory cost is negligible for ~10 panels
- CoworkSidebar is conditionally rendered only on chat tab — that stays as-is (outside Tabs)
- Existing `useEditorTabs` hook drives `activeTab` state — no store changes needed, just wire `<Tabs value={activeTab}>`
