# Plan: Implement TUI sidebar title expansion

**Created:** 2026-09-09 12:25:24 +08
**Status:** Draft

## Context

The TUI sidebar currently wraps session titles to at most three rows and truncates longer titles. The requested behavior is a collapsed-by-default title that toggles to a vertically expanded title when clicked, while preserving the existing `✦ gen` action. The review found that rendering, hit-testing, title selection, short-terminal behavior, and session replacement paths must be designed together.

User decisions:
- Expanded mode reflows the title so the final title row reserves space for `✦ gen`; it must not truncate merely because of the button.
- Dragging the title selects/copies title text rather than toggling.
- On short terminals, prioritize the title; lower sidebar sections may disappear, but the rendered frame must remain within terminal height.

## Goals

- Keep the sidebar fixed at 38 columns.
- Add collapsed/expanded transient state, collapsed by default.
- Toggle only on a click in the title region, never on a title drag or gen-button click.
- Show the complete title in expanded mode whenever terminal height permits, with final-row reflow around the gen button.
- Keep rendering, hit-testing, selection coordinates, and gen-button geometry consistent.
- Reset expansion on `/new`, `/session load`, and other conversation replacement paths that replace the active session.
- Preserve the terminal-height invariant and existing sidebar interactions.

## Approach

1. Add a shared title-layout helper that normalizes the title, computes collapsed or expanded rows, reserves the gen-button width on the final row, and reports title/gen hit rectangles. In expanded mode, reflow words so the last row has enough capacity for the button; do not truncate for button placement.
2. Add transient model state and a header-aware sidebar selection origin. Header rows participate in the same screen-coordinate selection model as sidebar content. A click with no movement toggles; an active drag copies selected title/sidebar text.
3. Use available height to prioritize the expanded title. The sidebar body is allowed to collapse to zero visible rows when necessary, while the overall render remains terminal-height-safe.
4. Reset the transient flag wherever the active conversation/session is replaced, including `/new` and `/session load`.
5. Add focused tests that drive actual press/motion/release events and verify render geometry, button isolation, overflow, selection, and resets.

## Implementation Steps

1. Update the design spec through the knowledge writer with the user-approved reflow, title-selection, title-priority, shared-layout, and session-load decisions.
2. Run Modern Go guidance for `internal/tui/model.go` and relevant test files.
3. Implement the model state and shared layout helper; route render, height, hit-testing, and selection through it.
4. Wire press/motion/release behavior, keeping gen-button clicks separate and title drags selectable.
5. Reset state on all active-session replacement paths.
6. Add/adjust focused tests.
7. Format, run targeted tests, inspect diagnostics, and review the final diff without touching unrelated user changes.

## Risks & Considerations

- Lipgloss/ANSI width must be measured using visual width, not byte length.
- The final title row has less text capacity because the gen button is rendered there; wrapping must reserve that capacity before row construction.
- Header selection needs a stable raw/styled line coordinate space so copied text matches visible rows.
- Extremely short terminals may render no sidebar body rows; title and frame height must remain coherent.
- Existing working-tree changes are unrelated and must not be reverted or included in edits.
- Go formatting and tests should be limited to the touched TUI files where practical.
