# Plan: Allow null/unset for all web UI model fields

## Goal
All model fields in the web UI settings should allow setting null or not set (empty). This means:
1. Users can clear a model selection back to empty/unset
2. Backend APIs accept empty model values
3. UI displays "Not set" when model is empty

## Current State

### Backend Handlers That REJECT Empty Model
1. `HandleSetModel` (handler_config.go:29): `req.Model == ""` → 400 error
2. `HandleSetSmallModel` (handler_config.go:213): `req.Model == "" && req.Enabled == nil` → 400 error
3. `HandleSetAdvisor` (handler_config.go:300): `req.Model == "" && req.Provider == nil && ...` → 400 error
4. `HandleSetOcrModel` (handler_config.go:435): `readBodyJSON` fails → 400 error
5. `HandleSetMaskModel` (handler_config.go:655): `readBodyJSON` fails → 400 error

### Backend Handlers That ALREADY Accept Empty Model
1. `HandleSetRecapConfig` (handler_config.go:782): No validation
2. `HandleSetCommitMsgConfig` (handler_config.go:829): No validation
3. `HandleSetCompactConfig` (handler_config.go:866): No validation
4. `HandleSetOcrConfig` (handler_config.go:473): No validation

### Frontend Components
- **ModelDialog.tsx**: Model picker with search, no "Clear" option
- **ModelDefaultsForm.tsx**: small model (immediate), recap model (form save)
- **AdvisorForm.tsx**: model (form save)
- **OcrForm.tsx**: openai.model (form save)
- **CommitMsgForm.tsx**: model (form save)
- **CompactForm.tsx**: summary_model (form save)
- **SecurityForm.tsx**: mask model (form save)
- **ImageGenForm.tsx**: model (text input, already accepts empty)

## Implementation Steps

### Step 1: Update Backend Handlers (5 handlers)

**1.1 HandleSetModel (handler_config.go:29)**
- Remove the `req.Model == ""` check
- Allow empty model to be saved

**1.2 HandleSetSmallModel (handler_config.go:213)**
- Change condition from `req.Model == "" && req.Enabled == nil` to just `req.Enabled == nil && req.Model == ""`
- This already allows `{"model": ""}` when `enabled` is also provided

**1.3 HandleSetAdvisor (handler_config.go:300)**
- The current logic already allows partial updates
- Just need to ensure empty model is accepted (it already is when other fields are provided)

**1.4 HandleSetOcrModel (handler_config.go:435)**
- Remove the model requirement check
- Allow empty model string

**1.5 HandleSetMaskModel (handler_config.go:655)**
- Remove the model requirement check
- Allow empty model string

### Step 2: Add "Clear" Button to ModelDialog (ModelDialog.tsx)

**2.1 Add Clear button at top of model list**
- Add a "Clear" or "Unset" button above the model list
- When clicked, call the appropriate handler with empty string
- For immediate-persist purposes (main/small/advisor), call the API directly
- For form-owned purposes, call `onPick` with empty string

**2.2 Update handleSelect to handle clear**
- Add a new `handleClear` function
- For main: `api.setConfigModel("")`
- For small: `api.setSmallModel("")`
- For advisor: `api.setAdvisorFull({ model: "" })`
- For form-owned: `onPick?.(purpose, "")`

### Step 3: Verify Settings Forms Display Empty Correctly
